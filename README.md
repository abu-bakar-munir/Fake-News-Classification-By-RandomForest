# Fake-News-Classification-By-RandomForest
This is a project in which we use random forest to classify that either a news is legimate or news is false.

# Project Description
This project aims to build a simple fake-news detection model using machine learning and text preprocessing. Given a dataset of news articles/titles, the code:

cleans and preprocesses text (lowercasing, removing stop-words, lemmatization),

vectorizes text data using TF-IDF,

splits data into train/test sets,

trains a classifier (Random Forest), and

evaluates performance (accuracy, confusion matrix, classification report).
